## Rules of use

1. An entry is an evidence pointer, never a new assertion of an already-consumed execution slot or signed immutability.
2. External evidence remains in its separately checked custody location; do not copy bulk evidence into the repository by default.
3. Preserve versioned artifacts, N1–N6, SHA-256 and author/provenance records without retrospective rewriting.
4. A future successor record is additive. The category does not authorize code execution, UTM, Git staging, commit, push, or transfer to Pilot 1.
5. The project owner approved the category, index name, and ownership on 2026-10-29 without authorizing Git writes at that time. Any initial filing must be independently authorized and reconciled; the presence of this index is not proof of authorization or operational closure.
